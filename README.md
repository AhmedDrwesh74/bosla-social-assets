# bosla-social-assets

Public image assets for BOSLA AI (بوصلة AI) social posts. Buffer reads images from the raw URLs here.

- Everything in this repo is public. Put only finished, approved social assets here — nothing internal.
- Layout: `<platform>/<YYYY-MM-DD>-<slug>/<n>.png` (n = image order in the post).
- Raw URL: `https://raw.githubusercontent.com/AhmedDrwesh74/bosla-social-assets/main/<path>`
- Files are never edited in place once a post is scheduled: a changed image gets a new folder or file name.
